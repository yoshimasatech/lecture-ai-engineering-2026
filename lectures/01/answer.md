# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：基礎は同じ質問を3回ずつ実行して回答の違いを比較する、実装は会話履歴を保ったまま続けて質問できるようにする、発展は応答時間とトークン数を計測して比較する、という回答だった。
- 用語集の正しい意味と比べて気づいたこと：モデルは講座固有の用語集を参照していないため、正しい3レベルを知らない可能性がある。一般的な説明から推測して、もっともらしく回答することもある。
- 表示できたトークン数（入力 / 出力）：`3.5-flash-lite` では「LoRAとは何ですか？」が `7 / 622`、「3レベルとは何ですか？」が `21 / 461` だった。

## 宿題

- 取り組んだレベル：発展
- やったこと：`app/ask.py` に `time.perf_counter()` による応答時間の計測を追加し、同じ2問を2モデルで実行した。出力形式は `[metrics] time=..., input_tokens=..., output_tokens=...` とした。
- 結果：

	| モデル | 質問 | 応答時間 | 入力 / 出力トークン |
	|---|---|---:|---:|
	| `gemini-3.5-flash-lite` | LoRAとは何ですか？ | 3.58秒 | 7 / 622 |
	| `gemini-3.5-flash-lite` | 3レベルとは何ですか？ | 2.43秒 | 21 / 461 |
	| `gemini-3.5-flash` | LoRAとは何ですか？ | 44.92秒 | 7 / 575 |
	| `gemini-3.5-flash` | 3レベルとは何ですか？ | 503で失敗 | - |

	`flash-lite` は今回の測定では `flash` より速く、出力トークン数は質問内容によって変わった。ただし各条件を1回しか測っていないため、平均値とはいえない。
- 気づき・疑問：入力トークン数は質問文の長さに左右され、出力トークン数はモデルの回答の長さに左右される。応答時間は出力トークン数だけでは決まらず、モデルの混雑やネットワークの影響も大きい。無料枠にはモデル・プロジェクトごとの1分あたり、1日あたりなどの制限があり、短時間に比較実験を繰り返すと `429` のレート制限になる可能性がある。今回は `gemini-3.5-flash` で `503`（モデル混雑）も発生した。実験ではリクエスト間隔を空け、公式のレート制限表を確認し、429や503が出た場合は待ってから再試行する必要がある。
